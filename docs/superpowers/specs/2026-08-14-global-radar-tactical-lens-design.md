# 全局雷达与战术镜头地图设计

日期：2026-08-14

## 1. 目标

在现有战场情报中心中，用“全局雷达 + 热区聚合 + 战术镜头”解决以下问题：

- 地块坐标跨度大、数据稀疏时，用户看到大面积空白；
- 拖拽或缩放后不知道当前处于世界何处；
- 全局态势与单格详情无法同时观察；
- 频繁跳转 WID、风险点、事件后难以返回上一视窗。

本设计保留右侧地块详情与底部 WorldState 时间线，不改变只读边界。

## 2. 总体布局

采用已确认的 A+B 融合方向：

```text
┌──────────────────────────────────────────────────────────────────┐
│ 图层 / WID 定位 / 显示层级 / WorldState / 刷新                  │
├──────────────────────────────────────────────┬───────────────────┤
│                                              │ 选中地块详情      │
│ 全局态势画布                                 │ 风险 / 行军       │
│ - 远景：热区光团                             │ 战报 / 证据       │
│ - 中景：战区轮廓与密度                       │                   │
│ - 近景：真实地块                             │                   │
│                                              │                   │
│ ┌─────────────┐                              │                   │
│ │ 全局小雷达  │  缩放 / Home / 前进后退     │                   │
│ └─────────────┘                              │                   │
├──────────────────────────────────────────────┴───────────────────┤
│ WorldState 变化时间线                                            │
└──────────────────────────────────────────────────────────────────┘
```

主地图与雷达共享同一份只读 WorldState 投影。

## 3. 三级语义缩放

地图不是对 Canvas 做简单几何放大，而是根据当前可视范围切换语义层级。

### 3.1 远景：全局热区

触发条件：

- 可视行数或列数大于 120；或
- 单格屏幕尺寸小于 3 像素。

展示：

- 不逐格绘制；
- 将已知地块按屏幕空间网格聚合；
- 每个热区显示地块数、最高风险、敌我构成和最近变化；
- 光团大小表示地块数量；
- 颜色表示主导状态：
  - 绿色：己方/友方；
  - 红色：敌方或高风险；
  - 黄色：近期变化或关注；
  - 蓝色：未知/中性；
- 双击或滚轮放大进入中景；
- 点击热区后右侧显示热区摘要，不伪装成单格详情。

### 3.2 中景：战区轮廓

触发条件：

- 可视行列在 41–120；或
- 单格尺寸为 3–8 像素。

展示：

- 绘制已知地块形成的稀疏“地块岛”；
- 保留高风险、关注、行军密度和变化边界；
- 显示当前战术镜头框；
- 点击地块岛自动将战术镜头移动到该区域；
- 双击进入近景。

### 3.3 近景：真实地块

触发条件：

- 可视行列不超过 40；且
- 单格屏幕尺寸至少 8 像素。

展示现有真实 WID 地块：

- 土地等级；
- 归属角标；
- 新鲜度；
- 行军；
- 关注状态；
- 选中状态；
- 放大后等级文字。

点击地块加载右侧详情。

## 4. 全局小雷达

小雷达常驻主地图左下角，不随主画布滚动。

### 4.1 雷达内容

- 使用 `dataBounds` 映射整个已知地块范围；
- 只绘制聚合密度，不逐格绘制；
- 显示敌方、己方、风险与关注热点；
- 当前主画布范围使用发光矩形框表示；
- 当前选中 WID 使用十字或亮点表示。

### 4.2 雷达交互

- 点击雷达任意位置：主地图以该位置为中心平移；
- 拖动视窗框：连续更新主地图中心；
- 滚轮：缩放主地图，不缩放雷达本身；
- 双击热点：进入该热点的战术镜头；
- 雷达不可完全隐藏，只允许折叠为 36px 小按钮。

## 5. 战术镜头

战术镜头是主地图当前精确视窗，不是另一个独立数据源。

- 默认大小为 20×20；
- 可以拖动；
- 可以缩放到 10×10、20×20、40×40；
- 当前镜头始终同步到小雷达；
- 定位 WID、点击事件或热区时，镜头平滑移动到目标；
- 用户手动拖动后不被自动刷新重置；
- WorldState 增量只更新镜头内受影响区域。

## 6. 导航防丢失

### 6.1 常驻操作

地图右下角提供：

- `−`：缩小；
- `Home`：回到自动推荐视窗；
- `+`：放大；
- `Back`：上一视窗；
- `Forward`：下一视窗。

### 6.2 视窗历史

以下操作写入浏览器内存历史：

- 热区跳转；
- WID 定位；
- 时间线跳转；
- 雷达点击；
- 拖拽结束；
- 缩放结束。

连续拖动过程不逐帧写历史，只在手势结束时写一次。

历史最多保存 30 条，不写数据库。

### 6.3 地址与状态

当前状态保存：

- bounds；
- zoom level；
- selected WID；
- layer state。

可写入 URL hash 或 `history.replaceState()`，页面刷新后恢复；如果恢复范围无数据，则回退到 `suggestedBounds`。

## 7. 热区聚合模型

聚合只用于展示，不修改原始地块数据。

前端接收当前需要的边界与聚合级别：

```text
GET /api/intelligence/world/overview
  ?rowUp=
  &rowDown=
  &colLeft=
  &colRight=
  &bucketRows=
  &bucketCols=
```

返回：

```json
{
  "worldStateVersion": 8,
  "dataBounds": {
    "rowUp": 62,
    "rowDown": 224,
    "colLeft": 1313,
    "colRight": 1488
  },
  "buckets": [
    {
      "rowUp": 200,
      "rowDown": 219,
      "colLeft": 1460,
      "colRight": 1479,
      "tileCount": 46,
      "riskMax": 72,
      "riskAverage": 31.4,
      "selfCount": 12,
      "allyCount": 9,
      "enemyCount": 18,
      "unknownCount": 7,
      "armyCount": 3,
      "changeCount": 8,
      "focusWid": 2141488
    }
  ]
}
```

约束：

- bucket 数不超过 2,500；
- 空 bucket 不返回；
- 风险仍由单格风险服务计算，聚合层只汇总；
- `focusWid` 必须是 bucket 内真实存在的 WID；
- 返回数据带 WorldState 版本和新鲜度。

## 8. 前端模块

拆分为：

### `static/intelligence-map.mjs`

- 真实地块绘制；
- 坐标换算；
- hit test；
- bounds、pan、zoom。

### `static/intelligence-map-overview.mjs`

- 语义缩放层级判断；
- bucket 光团绘制；
- 地块岛轮廓；
- 雷达绘制与雷达 hit test；
- 主视窗矩形映射。

### `static/intelligence-map-navigation.mjs`

- 视窗历史；
- Home / Back / Forward；
- WID、事件、雷达跳转；
- URL 状态恢复；
- 动画插值与 reduced-motion 降级。

### `static/intelligence-center.js`

- 调用 API；
- 管理选中实体；
- 协调右侧详情、时间线和地图模块；
- 不直接承载绘制算法。

## 9. 动画和视觉

- 热区使用两层低透明脉冲环；
- 高风险热点使用红色呼吸光；
- 己方热点使用绿色稳定光；
- 战术镜头使用青色双边框与十字参考线；
- 跳转动画为 220–320ms ease-out；
- 新增地块短暂闪烁一次，不持续闪烁；
- `prefers-reduced-motion` 下关闭脉冲与平滑移动；
- 动画不改变风险含义，不用粒子数量表示未经验证的数据。

## 10. 性能

- 单帧目标不超过 16ms；
- 每帧最多绘制 2,500 个 bucket 或 2,500 个真实格；
- Canvas 使用 DPR 上限 2；
- resize、wheel 和 pointermove 使用 requestAnimationFrame 合并；
- API 请求使用 AbortController 取消旧视窗请求；
- 主视窗结果按 `worldStateVersion + bounds + mode` 缓存；
- SSE 增量只使受影响 bucket/地块失效；
- 页面不可见时暂停动画。

## 11. 无数据与错误状态

- 无 WorldState：展示“等待 5026 基线”，不展示虚拟热区；
- 有 WorldState 但无地块：展示覆盖与数据边界；
- 恢复的历史视窗无数据：显示提示并提供 Home；
- WID 不存在：保持当前视窗，不跳到空白区域；
- 聚合 API 失败：回退到现有 viewport，但仍保留雷达边界；
- stale 数据保留显示并增加斜线/灰化，不当作实时结论。

## 12. 测试

### Python

- overview bucket 边界；
- bucket 数量上限；
- 空 bucket 不返回；
- focusWid 必须存在；
- 风险与归属聚合；
- WorldState 版本和 freshness；
- 空状态和 stale 状态。

### Node

- 语义缩放阈值；
- world/dataBounds 到雷达坐标映射；
- 雷达视窗框；
- bucket hit test；
- Home / Back / Forward 历史；
- 无效历史视窗回退；
- reduced-motion 动画降级。

### Chrome E2E

- 首次进入显示全局雷达；
- 远景显示热区而非空网格；
- 双击热区进入真实地块；
- 拖动雷达视窗框移动主地图；
- WID 定位后雷达框与详情同步；
- Home 返回建议视窗；
- Back / Forward 可恢复视窗；
- 375、768、1024、1440 宽度无溢出。

## 13. 只读边界

- 不主动发包；
- 不自动出征；
- 不修改游戏状态；
- 不根据聚合热区推断未知敌我关系；
- 热区点击只进行地图导航和只读查询。
