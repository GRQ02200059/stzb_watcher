# 单层完整侧栏导航设计

日期：2026-08-15

## 目标

将左侧导航改为无折叠、无分组、无“更多功能”的单层导航。

## 删除入口

- 13A2 队伍索引；
- 战区玩家；
- 战场消息；
- 战场监控；
- 打城排表；
- 数据同步；
- 玩家战绩；
- 分组武勋。

仅删除产品入口和命令面板项，底层页面、加载函数与 API 保留兼容。

## 直接展示标签

按以下顺序直接显示：

1. 实时战报；
2. 玩家队伍；
3. 自定义积分；
4. 全部战报；
5. 队伍统计；
6. 城池地图；
7. 同盟成员；
8. 打城考勤；
9. 同盟成员队伍；
10. 武将阵容；
11. 团数据；
12. 战斗模拟；
13. 州郡分布；
14. 设置中心；
15. 战场情报；
16. 阵容战法研究。

## 设计系统

- 删除“核心工作台”和“扩展工具”标签；
- 删除“更多功能 / 收起功能”按钮；
- 删除 `PRIMARY_TABS` 主次分类；
- 删除 `data-ds-primary`、`data-ds-secondary` 和 `ds-show-more` 行为；
- 所有 `<nav>` 直接子按钮统一增强图标与文字；
- 桌面继续使用固定侧栏；
- 移动端继续使用可滚动抽屉。

## 兼容

- 被删除入口对应的 `tab` 页面仍保留；
- 程序内部调用 `switchTab(id)` 仍可打开兼容页面；
- 本地保存的最后 Tab 若没有可见入口，回退到战场情报；
- 命令面板不再出现已删除入口。

## 验证

- 静态测试精确断言 16 个可见导航标签及顺序；
- 断言不存在更多按钮、导航分组和主次字段；
- Chrome E2E 逐个点击 16 个可见标签；
- 移动端抽屉无页面横向溢出；
- 完整测试套件通过。
