# App 页面化产品化 TODO

## 当前结论

App 端数据层和模块入口已经具备基础，但多数网页端能力还没有完成移动端页面化。后续重点不再是继续堆底层解析，而是把已有数据做成真正的 App 页面。

## 第一优先级

- [ ] 战报详情：从文本输出改为摘要卡、攻守双方、武将、战果指标、扩展字段的结构化页面
- [ ] 战场监控：从文本流改为实时监控 feed，展示队伍、玩家、同盟、目标坐标、最近战绩
- [ ] 排行中心：整合武勋、势力、同盟排行，形成卡片 + 榜单结构
- [ ] 同盟成员：成员列表、分组、势力、武勋、贡献等字段产品化
- [ ] 团数据：按分组/成员展示汇总卡片和明细表

## 第二优先级

- [ ] 州郡分布
- [ ] 城池地图
- [ ] 战场消息
- [ ] 玩家队伍 / 队伍统计
- [ ] 武将阵容

## 第三优先级

- [ ] 打城排表
- [ ] 13A2 队伍索引完整页
- [ ] 古代中国地图
- [ ] 自定义积分
- [ ] 完整模拟器界面

## 页面化标准

- 不再只输出大段文本
- 每个页面至少包含：摘要卡、主体列表/卡片、关键指标、空状态说明
- 优先复刻网页端的信息结构，再按移动端重新排版
- 高密度但可读，先结论后细节
