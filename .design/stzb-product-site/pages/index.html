一套内核，两种载体

核心数据模型、业务口径、阵容语义与模拟结果两端保持一致，不区分主端与次端。 你在桌面与移动之间自由切换，看到的都是同一套战场事实。

WEB 端

桌面宽屏指挥台

面向桌面宽屏的高密度指挥与多面板分析。

  • 桌面宽屏布局，多面板并行观察战场
  • Flask API + SSE 实时推送数据流
  • 浏览器仪表盘，无需安装即开即用

适合 持续监控、横向比较 与 团队管理 等长时段作业场景。

ANDROID 端

随身移动作战

面向移动设备的触控操作与本机运行。

  • VpnService 本机流量捕获与本地解析
  • SQLite 本地存储，Compose 触控界面
  • 全程本机运行，随开随用

适合 随身采集、快速查看 与 移动决策 等即时场景。

Why STZB Watcher

战场态势统一

地图格子、行军路线、实时部队、战报与世界事件汇聚到同一视图，战场全貌一屏尽览。

实时行动判断

追踪部队位置、路线、目标与新鲜度，结合阵容证据，让每一次出击判断都有迹可循。

阵容研究推演

结合历史样本、武将战法资料与 Kotlin 战斗引擎验证对阵，把经验沉淀为可复盘的推演。

团队协同管理
