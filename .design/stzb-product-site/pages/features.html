核心功能

战场之上，运筹于数据

STZB Watcher 是面向《率土之滨》的 Web + Android 双端战场数据平台，围绕情报、行动、组织、分析、系统五大业务域， 将战场态势、战报流水、队伍阵容与推演证据收拢进一处硬核工作区，让每一次调度都有据可依。

01 / 战场域

战场情报与实时部队

战场情报把全域地图、图层控制、风险态势与情报详情收拢到一处宽屏工作区；实时部队则聚合位置、路线、目标 与精确战报阵容，形成三栏指挥视图，让态势一目了然。

  • 全域地图与地图格子、图层控制统一收拢于宽屏工作区
  • 实时部队聚合位置、行军路线与目标于三栏指挥视图
  • 风险态势与世界事件同屏呈现，把握战场节奏
  • 精确战报阵容与情报详情联动，Web / Android 双端支持

02 / 模拟域

战斗模拟与批量推演

以 Kotlin 战斗引擎为核心，配置攻守双方阵容，执行单场或批量推演，并查看语义化的事件回放， 把「打之前先算清」变成可复用的日常动作。

  • 双方配置：分别设定攻守阵容与武将战法
  • 单场或批量推演，快速比较不同阵容组合
  • Kotlin 战斗引擎输出结果与语义化事件回放
  • Web / Android 双端均可执行推演

03 / 分析域

阵容战法研究

把历史对阵、战法执行链与模拟结果连接起来，为武将阵容与战法搭配提供对阵证据， 让研究结论可回溯、可复现，而非停留在经验直觉。

  • 连接历史对阵与战法执行链，形成对阵证据
  • 武将阵容与战法搭配研究，服务分析业务域
  • 与战斗模拟结果联动，研究结论可回溯复现
  • 排行与阵容研究在 Android 端原生呈现
