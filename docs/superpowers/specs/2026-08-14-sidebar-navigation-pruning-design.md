# 左侧导航精简设计

日期：2026-08-14

## 目标

精简左侧导航，移除以下入口：

- 战场总览；
- 排行中心 / 排行榜；
- 武勋统计；
- 势力值；
- 打城考勤 / 攻城考勤；
- 战场分析；
- 同盟势力；
- 游戏公告；
- 古代中国地图。

## 行为

- 只移除导航、命令面板、快捷入口与首页设置选项。
- 保留对应页面、加载函数和 API，兼容旧链接与内部调用。
- 默认首页改为 `tab33`“战场情报”。
- 若本地保存的首页或最后 Tab 已没有导航入口，自动回退到 `tab33`。
- `tab31` 战场总览保留为兼容页面，但不再作为左栏入口。

## 验证

- 静态测试断言左栏和命令面板不包含被移除入口。
- Node 行为测试验证无效历史首页回退到 `tab33`。
- Chrome E2E 验证初始页面为 `tab33`，剩余导航逐项可达。
